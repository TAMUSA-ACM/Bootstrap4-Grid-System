# Bootstrap4-Grid-System

Recreate [tamusa.edu](https://www.tamusa.edu)'s homepage using Bootstrap 4, focusing on responsive design with custom CSS and Google Fonts for enhanced typography.

## Project Overview

The Bootstrap4-Grid-System project aims to replicate the homepage of tamusa.edu with an emphasis on utilizing Bootstrap 4's powerful grid system. This project highlights responsive web design principles and integrates custom CSS and Google Fonts to enhance typography and overall aesthetics.

## Features

- **Responsive Design**: Leverages Bootstrap 4's grid system to ensure the layout adapts seamlessly across various devices and screen sizes.
- **Custom CSS**: Includes custom styling to refine and personalize the appearance beyond Bootstrap's default styles.
- **Google Fonts**: Enhances typography with carefully selected fonts from Google Fonts, improving readability and visual appeal.
- **Cross-Browser Compatibility**: Ensures the webpage functions correctly on major web browsers.

## Setup and Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/yourusername/Bootstrap4-Grid-System.git
   ```

2. **Navigate to the Project Directory**
   ```bash
   cd Bootstrap4-Grid-System
   ```

3. **Open `index.html` in Your Browser**
   - Simply open the `index.html` file in your preferred web browser to view the homepage.

## Usage

To modify or extend the project:

- Edit the HTML files in the root directory to change the structure or content.
- Update the CSS files in the `css` directory to alter styles or add new ones.
- Adjust the JavaScript files in the `js` directory for dynamic functionalities.
