# Bootstrap4-Grid-System

Welcome to the **Bootstrap4-Grid-System** repository! This project offers a practical exercise focused on recreating the grid section of the [tamusa.edu](https://www.tamusa.edu) homepage using the Bootstrap 4 framework. This exercise is perfect for those looking to learn and master responsive web design and styling using Bootstrap’s powerful grid system. 

## Features

- **Responsive Design**: Implement a responsive grid layout using Bootstrap 4 to ensure compatibility across various screen sizes and devices.
- **Custom Styling**: Integrate local CSS for additional styling to enhance the grid layout beyond Bootstrap's default styles.
- **Google Fonts Integration**: Enhance typography by incorporating Google Fonts into the design.
- **Image Utilization**: Utilize images for a realistic recreation of the webpage section.

## Setup and Installation

To get started with the Bootstrap4-Grid-System project, follow these steps:

1. **Clone the Repository**: 
   ```bash
   git clone https://github.com/yourusername/Bootstrap4-Grid-System.git
   ```

2. **Navigate to the Project Directory**:
   ```bash
   cd Bootstrap4-Grid-System
   ```

3. **Open the HTML File**:
   Open `index.html` in your preferred web browser to view the grid system in action.

4. **Edit Locally**:
   Use your favorite code editor to modify and experiment with the grid layout, styles, and fonts.
