# Bootstrap4-Grid-System

Recreate the [tamusa.edu](https://www.tamusa.edu) homepage grid using Bootstrap 4, focusing on responsive design and custom styling with CSS and Google Fonts.

## Project Overview

This project demonstrates the use of Bootstrap 4's grid system to create a responsive layout similar to the homepage of tamusa.edu. It emphasizes custom styling with CSS and integrates Google Fonts to enhance typography. This repository is ideal for those looking to understand responsive web design and grid layouts using Bootstrap 4.

## Features

- **Responsive Design**: Utilizes Bootstrap 4's grid system for mobile-first, responsive layouts.
- **Custom Styling**: Includes CSS for personalized styles beyond default Bootstrap components.
- **Google Fonts Integration**: Enhances the visual appeal with custom fonts.
- **Easy to Customize**: Modify and extend the layout and styles to fit personal or project needs.

## Setup and Installation

To set up the project locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/Bootstrap4-Grid-System.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd Bootstrap4-Grid-System
   ```
3. **Open `index.html` in your preferred web browser** to view the layout.

Ensure you have a stable internet connection to load Bootstrap and Google Fonts from their respective CDNs.

## Usage Examples

To adapt the grid system for your own project, modify the HTML structure within the `index.html` file. Customize the styles in `styles.css` to match your design requirements. Here is a simple example of a Bootstrap grid layout:

```html
<div class="container">
  <div class="row">
    <div class="col-md-6">
      <!-- Content for the first half -->
    </div>
    <div class="col-md-6">
      <!-- Content for the second half -->
    </div>
  </div>
</div>
```
